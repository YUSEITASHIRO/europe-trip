# ヨーロッパ周遊

卒業旅行（Dan・Hiroto・Tashiro）の日程・移動・宿泊・費用・持ち物を3人で見て編集するためのページ。

## 使い方

- 日付の行を押すと詳細が開き、右上の「✎ 編集」で移動・宿泊・予定・費用・リンクを書き換えられる。保存すると他の2人の画面にもすぐ反映される。
- 上部の「全員 / Dan / Hiroto / Tashiro」で、その人の予定だけに絞って表示する（別行動の日のため）。
- 費用は通貨（基本 EUR）を選んで入れると、欧州中央銀行の参照レートでユーロと円に換算して表示する。レートは開いたときと1時間ごとに取り直す（ECB の更新は平日1回）。
- 持ち物リストの項目は3人共有、チェックは各自の端末だけに保存。
- 個人のフライトは、旅程の飛行機の便ごと（その人が乗る便すべて）に予約内容を書き、本人の合言葉で暗号化して保存する。合言葉を忘れると誰にも戻せない。旅程から便を消すと、その便の登録は次に保存したときに消える。
- 地図の場所は地名でも Google マップの共有リンクでもよい。`/place/` を含む通常のリンクは地図を埋め込み、`maps.app.goo.gl` の短縮リンクは場所を読み取れないのでリンクだけを出す。

## 保存先（Firebase Realtime Database）の作り方

1. https://console.firebase.google.com/ に Google アカウントで入り、「プロジェクトを追加」。名前は任意、Google アナリティクスはオフでよい。
2. 左メニューの「構築」→「Realtime Database」→「データベースを作成」。場所は任意（日本から使うならシンガポール asia-southeast1 が近い）。「ロックモードで開始」を選ぶ。
3. 「ルール」タブを開き、次の内容に置き換えて「公開」。

   ```json
   { "rules": { ".read": true, ".write": true } }
   ```

4. 「データ」タブ上部の URL（`https://〜.firebasedatabase.app` または `https://〜.firebaseio.com`）をコピーし、`data.js` 1行目の `FIREBASE_URL = ""` の中に貼る。
5. 初めてページを開いたとき、`data.js` の `SEED` が保存先に書き込まれる。以後はアプリ上の編集が正本で、`SEED` を書き換えても反映されない。

このルールでは、保存先の URL を知っている人は誰でも読み書き・削除できる（URL はページのソースに載る）。Firebase からルールが安全でない旨の通知メールが来ることがある。

## ファイル

- `index.html` 本体
- `data.js` 保存先 URL と初期データ
- `airports.js` 空港の候補一覧。OurAirports（パブリックドメイン, https://ourairports.com/data/ ）から、定期便のある大・中規模空港で IATA コードを持つもの 3,244 件を抜き出したもの
- 駅・バスターミナルの候補は Photon（ https://photon.komoot.io/ 、OpenStreetMap のデータ）で検索する
